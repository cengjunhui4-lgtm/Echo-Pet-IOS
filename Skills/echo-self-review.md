# Echo Pet iOS Self Review

每次完成开发任务后执行项目质量审查：

1. Build Check：确认 Xcode Build，发现失败先修复。
2. Architecture Review：确认 View、ViewModel、Service、Model 职责分离。
3. Swift Code Review：检查命名、重复代码、潜在崩溃和未使用变量。
4. UI Review：确认 Minimal、Elegant、Warm、Calm，符合品牌色与留白。
5. MVP Scope Review：确认只覆盖 Life Timeline、LifePrint、Echo Companion、Memory Capsule。
6. User Experience Review：模拟首次打开 App，确认核心流程可理解。

输出格式：

## Build Status

✅ Pass

or

❌ Failed

## Code Quality

评分：1-10

## UI Quality

评分：1-10

## MVP Compliance

评分：1-10

## Problems Found

列出问题。

## Recommended Actions

给出下一步优化。
